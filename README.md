# Livraria

Sistema de gerenciamento de uma livraria, desenvolvido em Java com Maven.

Projeto acadêmico com foco em modelagem orientada a objetos e persistência de dados.

## Funcionalidades

- Cadastro de livros, autores e categorias
- (ajuste conforme o escopo real do projeto)

## Conceitos aplicados

- Programação Orientada a Objetos
- Modelagem de entidades e relacionamentos
- Organização de projeto em estrutura Maven

## Como executar

```bash
git clone https://github.com/SalvatoreDuke/Livraria.git
cd Livraria
mvn clean install
mvn exec:java
```

## Tecnologias

Java · Maven
